# QCM Project

## Description

This directory contains the source code of the Computer Science QCM Exam application.

---

## Requirements

- PHP 8+
- MySQL
- Apache (XAMPP/WAMP/MAMP)

---

## Installation

1. Import `sql/database.sql`
2. Configure `src/db.php`
3. Start Apache and MySQL
4. Open:

http://localhost/qcm_project/
